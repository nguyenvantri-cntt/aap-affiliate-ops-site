AAP Affiliate Ops

TikTok integration demo

Login Kit + Content Posting API end-to-end flow for app review

1. Open AAP web app

Operator opens AAP Affiliate Ops in the browser (Web platform).

2. Login Kit — authorize TikTok

User clicks Connect TikTok. App redirects to TikTok OAuth with scopes user.info.basic, video.upload, and video.publish (Direct Post).

3. User grants consent

TikTok shows consent screen. After approve, browser returns to Redirect URI /api/tiktok/callback and AAP stores refresh token.

4. Prepare affiliate package

Automation/AI Studio creates caption + media for an Affiliate-ready product. Human confirms once.

5. Content Posting API

Approved package is sent via Content Posting API: draft upload (video.upload) or Direct Post (video.publish) to the authorized creator account.

6. Result in TikTok

Video appears as draft inbox item or published post on the authorized TikTok profile. Operator reviews status in Publishing.
